# Patient Vital Signs Monitoring System

## Project Introduction

This project focuses on modeling a patient vital signs monitoring system using concepts from Real-Time Embedded Systems and Cyber-Physical Systems.

The system monitors patient vital signs, including heart rate, blood oxygen saturation (SpO2), and body temperature. Based on the received measurements, the system identifies normal, warning, and emergency conditions.

## Project Objectives

- Model the system using a Finite-State Machine (FSM).
- Identify system inputs, outputs, states, and transitions.
- Extend the FSM using state variables, guards, actions, and a timer.
- Combine multiple state machines to separate monitoring logic from safety management.

## Project Assignments

- Homework 01: Basic Finite-State Machine
- Homework 02: Extended Finite-State Machine
- Homework 03: Composition of State Machines

## Reference
